# SimpleAuth - Beginner-Friendly Full-Stack Authentication

A clean, modern, and complete login/register full-stack web application built from scratch with **Node.js**, **Express.js**, **SQLite**, and **Vanilla JavaScript**.

The full project code is located in the [`fullstack-login/`](./fullstack-login) directory.

---

## Quick Start

```bash
# Navigate to the backend directory
cd fullstack-login/backend

# Install dependencies (only needed once)
npm install

# Start the application
npm start
```

Then visit **[http://localhost:3000](http://localhost:3000)** in your browser!

For full documentation, architecture diagrams, API documentation, and beginner guide, please refer to:
- [fullstack-login/README.md](./fullstack-login/README.md)
